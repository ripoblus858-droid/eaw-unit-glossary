# affiliation_overrides.txt
#
# Manually force the affiliation(s) shown for specific units, regardless
# of what's declared in the XML, or inferred via garrison-spawner
# inheritance or filename inference (guessed_affiliation_from_filename).
# This is the highest-priority affiliation source -- for the rare cases
# where every other signal is wrong or missing for a specific unit and
# hand-fixing the source XML isn't practical.
#
# FORMAT: one entry per line --
#
#   <exact unit Name>,<affiliation1>[,<affiliation2>,...]
#
# Lines starting with # are comments; blank lines are ignored. Not
# passed by default -- point at this file with:
#
#   --affiliation-overrides affiliation_overrides.txt
#
