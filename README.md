# Unit Glossary Generator

Generates a browsable HTML glossary of every unit/squadron/structure in
an Empire at War: Forces of Corruption mod, split into an intro/splash
page plus one page per faction. Reads the mod's own XML directly, so
it stays in sync with your data as you edit it -- no manual upkeep of
a separate unit list.

## Requirements

- **Python 3** (any recent 3.x)
- **Pillow**, but only for the icon-conversion step:
  ```
  pip install --break-system-packages Pillow
  ```
- **MTD Editor** (or any tool that extracts a mod's `.tga` icon
  textures to a plain folder of files) for pulling icons out of the
  mod's Mega-Texture in the first place.

No other dependencies -- `generate_glossary.py` and the `glossary_gen/`
package it imports use only the Python standard library.

## Folder layout

Everything below assumes you're working from one folder containing
`generate_glossary.py`, the `glossary_gen/` package folder next to it,
and your own parameter files/images. A layout that matches the example
command later in this doc:

```
changed_files/
├── generate_glossary.py
├── glossary_gen/                  (the tool's own package -- don't edit)
├── convert_icons.py
├── run_glossary.bat
├── png_images/                    (unit icons -- from Step 2)
├── screenshots/                   (in-game screenshots you supply)
├── faction_images/                (faction logos, mod icon, gameplay banner)
├── excluded_names.txt
├── affiliation_overrides.txt
├── display_name_overrides.txt
├── ingame_images.txt
├── faction_images.txt
├── splash_text.txt
└── glossary_unit_order.txt        (generated by the tool -- see Step 4)
```

`generate_glossary.py` **must** be run as a script alongside its
`glossary_gen/` folder -- if you ever see
`ModuleNotFoundError: No module named 'glossary_gen'`, that folder
isn't sitting next to the script.

## Step 1: Extract icon textures with MTD Editor

Use MTD Editor to extract the mod's unit-icon Mega-Texture into a
plain folder of `.tga` files. The exact steps depend on MTD Editor's
own UI -- the only thing that matters for this pipeline is that you
end up with a folder containing `.tga` files, one per icon, named
however MTD Editor names them.

## Step 2: Convert icons to PNG (`convert_icons.py`)

The glossary reads pre-converted `.png` files, not `.tga` directly
(browsers can't render `.tga`). Run:

```
python convert_icons.py --input <tga_folder> --output png_images
```

- `--input`: the folder of `.tga` files from Step 1.
- `--output`: where the converted `.png` files go (this becomes your
  `--images-dir` in Step 4).
- `--ext`: output extension, default `png` (leave this alone unless
  you also change `--image-ext` to match in Step 4).

This also **lowercases every filename** on the way out (e.g.
`I_BUTTON_UNIT_EMPIRE_TIE.TGA` → `i_button_unit_empire_tie.png`) --
this matters, since the glossary generator itself always lowercases
the stem it builds from a unit's `Icon_Name` tag when looking up its
image. If you ever convert icons some other way, make sure you
replicate that lowercasing, or icons won't be found.

Run this once per mod version, or whenever the mod adds/changes icons.

## Step 3: Prepare parameter files

None of these are required -- the tool runs fine with none of them,
just with fewer features. Each is a plain text file you write by hand.
`#` starts a comment on its own line in every one of them, and blank
lines are ignored.

### `excluded_names.txt` -- units to always hide
One exact unit `Name` per line. Use this for entries that are only
ever used as garrison filler, leftover/debug content, etc.
```
Some_Debug_Unit
Old_Unused_Fighter
```

### `affiliation_overrides.txt` -- force a unit's shown faction(s)
One `<exact unit Name>,<affiliation1>[,<affiliation2>,...]` pair per
line. Overrides that unit's own `Affiliation` tag and every other
heuristic.
```
Shared_Hero,Empire,Rebel
```

### `display_name_overrides.txt` -- rename a card's title
One `<exact unit Name>,<display name>` pair per line. Only the first
comma splits the name from the text, so the display name itself may
contain commas -- useful for representing several merged variants as
one combined title.
```
181st_Alpha_Defender_Squadron,181st Alpha, Beta, Saber Squadrons
```

### `ingame_images.txt` -- in-game screenshot thumbnails
One `<exact unit Name>,<image filename1>[,<image filename2>,...]` pair
per line. Filenames are looked up under `--in-game-images-dir` exactly
as given (extension included).
```
Devastator_Star_Destroyer,devastator_bridge.png,devastator_hangar.png
```

### `faction_images.txt` -- faction logos and/or renamed labels
One `<faction name>,<logo filename>[,<display name>]` per line.
Matched case-insensitively against each faction's own affiliation
value. Either the logo or the display name may be left blank, but not
both.
```
Empire,empire_logo.png
CSA,,Confederate Systems Alliance
Rebel,rebel_logo.png,Rebel Alliance
```

### `splash_text.txt` -- the splash page's title/description/author
A `key=value` file (recognized keys: `title`, `description`,
`author`). Unlike every other file above, a value can span multiple
lines -- once a `key=` line starts, everything up to the next
recognized `key=` line (blank lines included, for paragraph breaks) is
part of that value. `description` and `author` accept raw HTML,
so a real `<a href="...">` renders as an actual link; `title` does
not (though a newline in it becomes a real line break in the visible
heading -- just not in the browser tab title, which can't contain
markup at all).
```
title=My Awesome Mod
description=A total conversion mod. Check out our
<a href="https://example.com">official page</a> for updates.

A second paragraph here.
author=Created by SomeModder, with help from the community.
```

### `glossary_unit_order.txt` -- manual row ordering
**Don't write this one by hand from scratch.** Run the tool once
*without* `--unit-order` at all -- it writes this file automatically,
capturing the exact default order (ascending by HP) it used. Edit
*that* file, then pass it back in via `--unit-order` on later runs.
Format:
```
[Empire]
consular.xml=Consular_R, Consular_E
tie_fighters.xml=TIE_Fighter, TIE_Interceptor

[Rebel]
x_wing.xml=X_Wing, Y_Wing
```
Reordering the comma-separated names on a line reorders rows within
that source file; reordering the *lines* within a section reorders
which file's whole block comes first. A row or file this doesn't
mention just falls back to the default order for whatever's missing,
appended after everything the file *does* specify -- so you never have
to keep it perfectly in sync as your roster changes.

## Step 4: Generate the glossary

### Why a `.bat` file, not pasting the command directly

`cmd.exe`'s `^` line-continuation becomes unreliable when pasted
directly into an interactive prompt, especially with quoted paths --
you can end up with the command silently cutting itself short partway
through. Running it as a saved `.bat` file avoids this, since batch
files are parsed as a whole script rather than typed/pasted line by
line. **Run `run_glossary.bat` by typing its name (or double-clicking
it) -- don't open it in an editor and paste its contents into the
terminal**, which would hit the exact same problem.

### Example `run_glossary.bat`

```bat
@echo off
python generate_glossary.py ^
	--dirs ^
	"C:\...\1770851727\Data\Xml\Units\Space" ^
	"C:\...\2794270450\Data\Xml\Units\Space" ^
	"C:\...\3229239424\Data\Xml\Units\Space" ^
	--excluded-names-file excluded_names.txt ^
	--affiliation-overrides affiliation_overrides.txt ^
	--display-name-overrides display_name_overrides.txt ^
	--projectiles ^
	"C:\...\3229239424\Data\Xml\PROJECTILES.XML" ^
	--output index.html ^
	--images-dir png_images ^
	--translations ^
	"C:\...\3229239424\Data\Text\xml\TranslationManifest.xml" ^
	--image-size 100 ^
	--image-background-color "#1a2345" ^
	--in-game-images ingame_images.txt ^
	--in-game-images-dir screenshots ^
	--faction-logos faction_images.txt ^
	--faction-logos-dir faction_images ^
	--splash-config splash_text.txt ^
	--mod-icon "faction_images\fft_logo.png" ^
	--gameplay-image "faction_images\eaw_orbital.png" ^
	--unit-order glossary_unit_order.txt ^
	--prune-unused-images unused_png_images

pause
```

`--dirs` takes multiple mod folders **in override order** -- if the
same unit `Name` is defined in more than one, whichever folder is
listed *last* wins, even if its definition lives in a differently-named
file. `pause` at the end just keeps the window open afterward so you
can read the output.

### What gets written

Given `--output index.html`, a run produces (in the same folder):

- `index.html` -- the splash page
- `index_empire.html`, `index_rebel.html`, ... -- one page per faction
  found among your units (plus `index_unaffiliated.html` if anything
  has no affiliation at all)
- `index_unit_order.txt` -- **only** written when `--unit-order` is
  *not* passed (see Step 3's note on this file)

If `--prune-unused-images` is given, it also moves (never deletes) any
file in `--images-dir` that no generated page actually references into
the folder you named -- run once with `--prune-unused-images-dry-run`
added first if you want to see what it *would* move before it touches
anything.

## Full flag reference

Run `python generate_glossary.py --help` for the authoritative,
always-up-to-date list with full descriptions. Summary:

| Flag | Purpose |
|---|---|
| `--dirs` | Mod folder(s) to scan, in override order (required) |
| `--output` | Output path for the splash page; per-faction pages are named from this |
| `--images-dir` / `--image-ext` | Where converted unit icons live, and their extension |
| `--image-size` / `--image-background-color` | Icon display size and background color |
| `--include-no-image` | Include units with no icon (excluded by default) |
| `--exclude-name-contains` / `--exclude-name-suffix` / `--exclude-name-exact` | Name-based exclusion filters |
| `--excluded-names-file` | File-based version of `--exclude-name-exact` |
| `--squadron-icon-suppress-file` | Squadrons whose own icon shouldn't lead their fighter gallery |
| `--translations` / `--translation-language` | Translation manifest file(s) and language |
| `--hide-untranslated` | Skip units with no real translated name |
| `--projectiles` | Standalone projectile/damage XML file(s), if not already under `--dirs` |
| `--affiliation-overrides` | Force a unit's shown affiliation(s) |
| `--display-name-overrides` | Rename a card's title |
| `--in-game-images` / `--in-game-images-dir` | Screenshot thumbnails per unit |
| `--faction-logos` / `--faction-logos-dir` | Faction logos and/or renamed labels on the splash page |
| `--splash-config` | Splash page title/description/author |
| `--mod-icon` | Small identity image on the splash page |
| `--gameplay-image` | Large banner image on the splash page |
| `--unit-order` | Manual row ordering (see Step 3) |
| `--prune-unused-images` / `--prune-unused-images-dry-run` | Move unreferenced icons out of `--images-dir` |
